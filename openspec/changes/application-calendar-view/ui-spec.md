# 投递日历视图 UI 规范 — `/applications?view=calendar`

> 设计依据：`ui-ux-pro-max` Heatmap (Calendar) + 自定义 CSS Grid 时间轴。沿用现有投递页色彩令牌（primary #1A56DB / indigo #6366F1 / amber #F59E0B / emerald #10B981）与 `card-flat` 基类。

## 一、页面目标

让用户一眼看到"我下周有多少场笔试/面试"、"有没有时间冲突"。提供月/周两个时间跨度，月视图看密度分布，周视图看具体时段和冲突。

## 二、结构分层

```
┌────────────────────────────────────────────────────────────────┐
│ 视图切换 Tab：[列表] [日程 ←active] [数据分析]                    │
├────────────────────────────────────────────────────────────────┤
│ ⚠️ 冲突告警条（有冲突时显示，红色背景条）                            │
│  「检测到 N 处时间冲突，可能影响面试安排」 [定位冲突 →]               │
├────────────────────────────────────────────────────────────────┤
│ 工具栏：[← 上一周/月] [本周/本月 回到当前] [下一周/月 →]            │
│         [月视图 | 周视图] 切换按钮                                 │
├────────────────────────────────────────────────────────────────┤
│ 【月视图 or 周视图 主内容区域】                                    │
└────────────────────────────────────────────────────────────────┘
```

## 三、月视图

- **网格**：`7 列 x 5-6 行` CSS Grid，列宽 `1fr`。
- **表头**：周一到周日标签（`text-xs text-muted font-medium`）。
- **日期格**：
  - 日期数字：`text-sm text-ink`；今天加 `bg-primary text-white rounded-full w-6 h-6 inline-flex items-center justify-center`。
  - 事件标记（最多显示 3 条）：
    - 笔试：`h-1.5 w-1.5 rounded-full bg-indigo-500`（紫色点）+ 公司简称截取前 4 字。
    - 面试：`h-1.5 w-1.5 rounded-full bg-amber-500`（琥珀色点）+ 公司简称。
  - 超过 3 条：`「+N」text-xs text-primary cursor-pointer` 点击展开浮层（absolute，z-20）列出当天全部事件。
  - 有冲突的日期：数字背景改为 `bg-red-50 ring-1 ring-red-300`。
- **非当月日期**：`opacity-30`。
- **事件点击**：打开对应投递的详情抽屉（复用现有）。

## 四、周视图（时间轴）

- **Y 轴**：时间刻度 08:00–22:00，每小时一格，格高 60px（总高 840px，`overflow-y-auto` 容器固定 600px 可滚动）。
- **X 轴**：7 天（周一~周日），等宽列。
- **事件块**：
  - 高度 = `(endTime - startTime) / 3600 * 60px`，最小高度 30px（防止 15 分钟面试太扁）。
  - 背景色：笔试 `bg-indigo-100 border-l-2 border-indigo-500`；面试 `bg-amber-100 border-l-2 border-amber-500`。
  - 内容：`text-xs` 公司名 + 轮次/类型。
  - 无 `scheduledEnd` 时默认按 1 小时渲染。
- **冲突处理**：同一天同一时段有重叠块时，并排排列（每块占当日列宽的 1/N，N=重叠数），冲突块左边框改为 `border-red-500`。
- **当前时间线**：横穿全宽的红色虚线 `border-dashed border-red-400`，每分钟更新定位。

## 五、冲突告警条

- 背景 `bg-red-50 border border-red-200 rounded-lg p-3`。
- 图标 `AlertTriangle` (lucide-react) `text-red-500`。
- 文案 `text-sm text-red-700`。
- 「定位冲突」按钮滚动到第一处冲突块并 highlight 闪烁（`animate-pulse` 2 秒）。
- 无冲突时隐藏。

## 六、交互与状态

- **加载**：骨架网格（月视图：7x5 空格 `animate-pulse`；周视图：4 列宽高随机灰条）。
- **空态**：无任何笔试/面试 → 居中 `CalendarClock` 图标 + "暂无笔面试安排，投递后系统将自动同步日程"。
- **错误**：`card-flat` 内居中"加载失败 · 重试"按钮。
- **快捷键**：← → 切换上/下周(月)；`T` 回到今天；`M`/`W` 切月/周视图。
- **URL 状态**：`?view=calendar&mode=month|week&date=2026-08-11`，deep-link 可分享。

## 七、响应式

| 断点 | 行为 |
|---|---|
| `>=1024px` | 月视图 7 列正常；周视图 7 列 + 时间轴 |
| `768px~1024px` | 月视图 7 列压缩（事件标记隐藏文字只留色点）；周视图保留但列更窄 |
| `<768px` | 默认切为"3 天视图"（只显示今天+明后两天），月视图隐藏但可手动切换 |

## 八、无障碍

- 月视图每个日期格 `role="gridcell"` + `aria-label="8 月 15 日，2 场面试"`。
- 周视图事件块 `role="button"` + `aria-label="字节跳动 一面，8 月 15 日 10:00-11:00"`。
- 冲突告警条 `role="alert"` + `aria-live="polite"`。
- 键盘导航：↑↓←→ 在日期格间移动，Enter 展开事件。
- `prefers-reduced-motion`：禁用冲突闪烁动画和时间线滚动动效。
