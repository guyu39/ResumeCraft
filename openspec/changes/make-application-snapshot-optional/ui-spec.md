## 页面目标

允许用户先保存职位并进入投递管道，快照关联作为可选的复盘信息，不再成为新建或编辑投递记录的阻断条件。保持现有投递表格、弹窗结构、配色和控件体系，不进行视觉改版。

## 影响范围

- 页面：`/applications`。
- 区域：新增/编辑投递弹窗中的“关联简历快照”分组。
- 不调整：主表格布局、详情抽屉、状态流转、分页和其他表单字段。

## 结构与文案

- “关联简历”保持必填和现有选择器。
- “关联快照”标签改为“关联快照（可选）”。
- 快照选择器第一项固定为“暂不关联版本”，值为空字符串。
- 有快照时，其余选项继续显示快照标签；没有快照时仍显示可操作的选择器，仅包含“暂不关联版本”。
- 删除“该简历暂无快照版本，请先在编辑页创建”的阻断式黄色空态。
- 弹窗左侧能力说明从“绑定简历快照，便于后续复盘”改为“快照可后续关联，便于按版本复盘”。

## 交互状态

- 新建投递：选择简历后默认保持“暂不关联版本”，不得自动选择第一个快照。
- 编辑投递：已有快照时显示现有关联；无快照时显示“暂不关联版本”。
- 更换简历：立即清空当前快照选择并重新加载新简历的候选快照。
- 快照加载失败：保留“暂不关联版本”，不阻止保存；不弹出额外错误提示。
- 保存中：沿用现有按钮禁用和“保存中”反馈。
- 页面不得因候选快照异步加载出现字段高度变化。

## 视觉规范

- 复用现有 `StyledSelect`，不新增卡片、提示条或装饰元素。
- 标签、字号、44px 触控高度、8px 圆角、边框和聚焦样式沿用当前表单规范。
- “可选”使用与标签一致的中性文字，不使用警告色。
- “未关联版本”使用中性灰文本，不使用错误或警告图标。

## 响应式与无障碍

- 保持现有 `md:grid-cols-2`：移动端单列，桌面端简历与快照双列。
- 375px、768px、1024px 和 1440px 下不得出现横向溢出或文本遮挡。
- 选择器保持键盘操作、可见焦点和现有 Listbox 语义。
- 不使用仅靠颜色表达“已关联/未关联”状态。

## 验收标准

- 没有任何快照的新简历可以完成新增投递。
- 用户可以在编辑投递时绑定、替换或清除快照。
- 更换简历后不会保留旧简历的快照 ID。
- 快照加载失败不阻断职位保存。
- 页面布局与现有投递弹窗保持一致。
