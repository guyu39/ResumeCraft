# 首页工作台 UI 规范（`/`）— 迭代 v3

> 设计依据：ui-ux-pro-max 检索（Newsletter / Content First 内容优先模式）结合项目既有 Flat 蓝灰设计体系。沿用现有令牌（primary/canvas/surface/line/ink/muted）。
> 本文件为 v2 的迭代补充，覆盖本轮布局调整：双栏布局、固定顶部导航、待办/新岗位改为右下角悬浮球（折叠/展开）、日报与 GitHub 改为 Tab 切换、主内容固定容器内滚动。

## 一、页面目标与使用场景

- **定位**：求职工作台首页。双栏布局：左栏主内容（AI 日报 / GitHub 最新项目 Tab 切换 + 简历项目推荐），右栏行动区（待办 + 今日新增岗位）以右下角悬浮球形式常驻，支持折叠/展开。
- **核心场景**：固定导航始终可见；用户专注浏览左栏内容（容器内滚动），随时点开右下角悬浮球查看待办/新岗位数字与列表。
- **设计原则**：内容优先（Newsletter）；行动区悬浮化、不占用内容区；主内容固定容器大小、容器内滚动。

## 二、页面结构分层与组件排布

```
┌────────────────────────────────────────────────────────────────┐
│ ① HomeHeader 顶部导航（fixed 固定，h-14，不随页面滚动）          │
├───────────────────────────────────────────────┬────────────────┤
│ ② 左栏主内容                                │ ③ 右下角悬浮球   │
│ ┌ AI 日报面板（Tab 切换）──────────────────┐ │ ┌ 待办球 ●N ──┐ │
│ │ [日报 | GitHub]  ⚙                     │ │ ├─────────────┤ │
│ │ 固定 h-[560px] 容器内滚动                │ │ │ 点击展开面板  │ │
│ │  日报：资讯列表+启示折叠+趋势关键词       │ │ │（固定右下角） │ │
│ │  GitHub：仓库列表固定格式                │ │ └─────────────┘ │
│ └─────────────────────────────────────────┘ │ ┌ 新岗位球 ●N ─┐ │
│ ┌ 简历项目推荐 ───────────────────────────┐ │ │ 点击展开今日+  │ │
│ │ 固定 h-[560px] 容器内滚动                │ │ │ 昨日新增岗位  │ │
│ │ 卡片：名称/定位/难度/趋势关联→展开详情   │ │ └─────────────┘ │
│ └─────────────────────────────────────────┘ └────────────────┘ │
└────────────────────────────────────────────────────────────────┘
```

**桌面双栏（`>=1280px`）**：`grid-cols-2` 左=日报 Tab 面板 / 右=简历项目推荐，两列并排（内容充足时左右两列）。
**移动/平板（`<1280px`）**：单列堆叠（日报 → 项目推荐），悬浮球仍固定在右下角。

## 三、统一视觉规范

沿用 v1/v2 全部令牌体系。新增：
- Tab 切换：`bg-slate-100` 容器 + 选中项 `bg-white text-primary shadow-sm` 胶囊。
- 悬浮球：主色圆角胶囊 `bg-primary text-white`，数字 `tabular-nums`；展开面板 `w-[min(380px,calc(100vw-40px))]`、固定 `h-72` 内容区、圆角 16px、`shadow-2xl`。
- 固定导航：`bg-surface/95 backdrop-blur`。

## 四、全量交互状态

- **顶部导航**：fixed 固定，页面滚动时始终在顶部；主内容 `pt-20` 补偿导航高度。
- **悬浮球**：常态显示图标 + 数字；悬停轻微上浮（`-translate-y-0.5`）；点击切换展开/收起对应面板；展开面板带关闭按钮，面板浮于内容之上（`fixed bottom-24 right-5 z-50`）。
- **待办面板**：点击行跳 `/applications?id=`；底部「前往投递管理」。
- **新岗位面板**：点击行跳原文/`/jobs`；显示「今天开放/昨天开放」标签；底部「前往招聘聚合」。
- **Tab 切换**：日报 / GitHub 互斥切换，切换保留各自滚动位置；`aria-pressed` 语义。
- **主内容容器**：`h-[560px] overflow-y-auto no-scrollbar`，容器内滚动（用户明确要求），不出现页面级横向滚动。
- **加载/空态/错误态**：各区块独立骨架屏、空态文案、错误 + 重试。

## 五、响应式适配规则

| 断点 | 布局 |
|---|---|
| `>=1280px` | 双栏：左=日报Tab，右=项目推荐（内容充足左右两列）；悬浮球在右下角 |
| `<1280px` | 单列：日报 → 项目推荐 堆叠；悬浮球仍固定右下角 |
| 悬浮面板 | 宽度 `min(380px, 100vw-40px)`，窄屏不超出视口 |

- 无页面级横向滚动；主内容仅容器内纵向滚动。

## 六、无障碍与易用性

沿用 v1 全部要点。新增：Tab 用 `aria-pressed`；悬浮球按钮带 `aria-label` 与 `aria-expanded`；面板可关闭（X 按钮）；动效遵循 `prefers-reduced-motion`；悬浮球不遮挡主内容操作（`z-50` 层级、右下角定位）。
