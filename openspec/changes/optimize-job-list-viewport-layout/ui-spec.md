# `/jobs` 满视口招聘表格 UI 规范

## 页面目标与场景

- 面向连续扫描、筛选和翻页招聘信息的求职用户，优先保证表格数据密度和分页可达性。
- 用户在任意表格滚动位置都能直接翻页，并可从页头快速进入“我的简历”或“投递管理”。
- 页面继续使用表格，不改为卡片，不增加说明性横幅或装饰元素。

## 页面结构

1. 满动态视口页面根容器：纵向 flex，禁止文档级滚动。
2. 紧凑顶部工具栏：标题、行业/类型/关键词筛选、“我的简历”“投递管理”集中排列；移除手动同步、独立说明文案、“筛选”标签和顶部重复结果计数。
3. 筛选控件：桌面宽屏位于标题与操作之间；窄屏时行业和类型同排，关键词搜索占下一整行。
4. 内容区：占据所有剩余高度；错误、加载、空态和表格四种状态互斥展示。
5. 表格：满宽、满剩余高度，双轴滚动，隐藏滚动条，表头固定在滚动区顶部。
6. 分页栏：存在结果时始终位于视口底部，独立占位，不覆盖表格。

## 视觉规范

- 继续使用项目现有蓝灰色体系：页面背景 `slate-50`，表格背景白色，边界 `slate-200`；列表结构区域以中性灰为主，蓝色仅保留给导航和输入焦点。
- 不采用 UI 检索输出的绿色方案或新字体，保持跨页面一致性和现有字体配置。
- 页面区域不使用浮动卡片效果；表格只保留上下边界和必要分隔线，圆角不超过 8px。
- 页头标题保持 `18-20px/600`，表格辅助文本保持 `12-13px`；不使用视口缩放字号或负字距。
- 导航使用 Lucide `FileText` 与 `BriefcaseBusiness`，图标尺寸 16px，按钮文字不省略。
- 表头使用纯中性的 `gray-100/95` 背景、`gray-200` 分隔线、`gray-700` 文字与 12px/600 字重，不使用偏蓝背景、全大写或额外字距。
- 分页使用白底、`slate-200` 上边界和不超过 8px 圆角；当前页为 `slate-900`，普通页为白底中性文字。
- 交互控件保持至少 40px 高；移动端通过换行避免压缩文字。

## 交互状态

- 常态：分页和页头始终可见，表格内容独立滚动。
- 悬停：导航按钮使用现有蓝色浅底反馈；表格行保持浅灰底反馈。
- 点击：导航分别进入 `/` 与 `/applications`；行业或类型已展开时，点击另一筛选一次即可关闭当前面板并打开目标面板。
- 加载：首屏使用现有表格骨架并占满内容区，分页在已有数据刷新时保持可见且禁用。
- 空态：占满内容区居中展示现有空态和清除筛选操作；无结果时不展示无意义分页。
- 错误态：错误提示位于内容区顶部，并提供现有重试操作。
- 滚动：不显示浏览器滚动条，不拦截滚轮、触控板、键盘和触屏滚动。
- 自动更新：页面不展示手动同步按钮；每小时刷新列表和筛选枚举，不弹成功提示或打断浏览。

## 响应式规则

- `>= 1280px`：标题、筛选和两个导航按钮尽量单行排列，顶部工具栏目标高度不超过 64px。
- `768-1279px`：标题与操作位于首行，筛选控件紧凑排列在下一行；表格保持横向滚动能力。
- `< 768px`：标题、两个导航按钮和筛选控件分层排列；操作按钮同排，两个下拉同排，关键词搜索全宽；分页使用现有纵向布局，表格通过触屏横向滑动查看完整列。
- 375px、768px、1280px 和 1440px 均不得出现控件重叠；分页必须位于当前视口内。

## 无障碍与易用性

- 使用语义化 `header`、`main`、`table` 和 `button`；导航按钮文字明确，不依赖图标猜测。
- 图标设置为装饰性上下文，由按钮文字提供可访问名称。
- 表头在表格滚动时保持可见，减少列含义丢失。
- 保留现有键盘焦点与按钮 disabled 语义；隐藏滚动条不禁用键盘滚动。
- 颜色对比延续现有可读组合，状态信息不只依赖颜色表达。
