## Context

`/jobs` 当前以 `min-h-screen` 加文档流展示页头、筛选、表格和分页。表格容器只处理横向溢出，页面数据较多时需要滚动整页才能看到分页；同时现有 `thin-scrollbar` 仍展示自定义滚动条。项目已经提供 `.no-scrollbar`，可以在保留滚动能力的情况下跨浏览器隐藏滚动条。

## Goals / Non-Goals

**Goals:**

- 让招聘表格填满固定区域之外的全部可用视口。
- 保证分页在有数据时始终位于视口底部，不与表格内容重叠。
- 隐藏表格区域的原生滚动条，同时支持滚轮、触控板、键盘和触屏滚动。
- 补充“我的简历”和“投递管理”两个清晰的顶级页面入口。
- 支持两个筛选下拉单击直接切换，并降低表头、分页区域的视觉噪声。
- 取消页面手动同步入口，由服务端每小时自动同步招聘源数据。
- 保持桌面端数据密度，并让窄屏仍可操作。

**Non-Goals:**

- 不修改招聘数据接口、筛选条件或分页规则。
- 不删除现有手动同步 API，避免破坏其他调用方。
- 不新增 `/application` 单数路由，投递管理继续使用现有 `/applications`。
- 不重构表格为卡片，也不引入虚拟滚动或第三方表格库。
- 不调整全局配色、字体和组件设计系统。

## Decisions

### 1. 使用视口高度 Flex 布局，不使用覆盖式 Fixed Footer

页面根节点使用动态视口高度并隐藏文档级溢出。筛选控件并入紧凑页头，页头和分页区保持 `shrink-0`，中间内容区使用 `min-h-0 flex-1`。分页因此始终在页面底部，又不会覆盖最后一行数据。

替代方案是给分页使用 `position: fixed` 并为表格添加等高底部留白；该方案容易在移动端安全区、分页高度变化和空态下产生遮挡，因此不采用。

### 2. 表格容器承担双轴滚动并隐藏滚动条

表格容器使用 `overflow-auto no-scrollbar`，表头使用 sticky 定位。滚动交互保持浏览器原生能力，只移除滚动条视觉；不拦截 wheel/touch 事件，也不实现自定义滚动逻辑。

### 3. 复用现有路由和视觉组件

“我的简历”跳转 `/`，“投递管理”跳转现有 `/applications`。导航按钮使用 Lucide 图标与文字标签，沿用当前蓝灰色按钮层级。删除页头手动同步按钮及其前端冷却状态，不删除后端同步 API。

### 4. 窄屏保留表格语义和横向触控滚动

表格继续使用现有最小宽度，窄屏用户可横向滑动查看列。页头操作允许换行，分页组件继续使用当前响应式纵向布局。此变更不把表格改成卡片，以保持职位比较效率和用户明确要求的表格形态。

### 5. 筛选控件并入顶部紧凑工具栏

移除页头说明文案与 `JobFilterBar` 自带的 sticky 背景、边框和“筛选”标签，由页面页头统一承载标题、筛选和操作。桌面宽屏按“标题 / 筛选 / 操作”排列；较窄视口允许筛选整体换到下一行，移动端两个下拉并排、关键词搜索占满下一行。顶部不重复展示总数，分页栏继续提供总数信息。

### 6. 招聘筛选使用非模态 Listbox

Headless UI `Listbox.Options` 默认启用 modal，会在面板展开时把同级控件设为 inert，导致第一次点击另一个筛选只能关闭当前面板。`StyledSelect` 增加可选的 `modal` 参数，招聘页的行业和类型筛选传入 `false`。外部点击逻辑仍会关闭旧面板，而目标按钮保持可交互，因此同一次点击继续打开目标面板；其他使用场景维持默认模态行为。

### 7. 服务端每小时同步，前端每小时刷新

招聘同步调度器默认间隔从 6 小时改为 1 小时，服务启动时仍立即执行一次。`JOB_SYNC_INTERVAL` 继续支持覆盖，并通过 Compose 和后端示例环境文件显式配置。前端 `/jobs` 每小时重新请求当前页与筛选枚举，使长时间打开的页面看到新数据；定时器随页面卸载清理。

### 8. 表头与分页采用中性工作台视觉

表头使用不带蓝色倾向的 `gray-100/95` 背景、`gray-700` 文字和 `gray-200` 分隔线，取消全大写和额外字距。分页使用白色背景和灰色边界，按钮圆角控制在 8px，当前页使用 `slate-900`，上一页、下一页及非当前页使用中性 hover，避免底栏成为页面最抢眼区域。

## Risks / Trade-offs

- [隐藏滚动条降低可滚动区域的可发现性] → 保留表格内容在边缘的自然截断，并确保滚轮、触控板和触屏操作有效；不隐藏关键分页操作。
- [移动浏览器地址栏导致 `100vh` 高度偏差] → 使用 `100dvh` 并保留 `h-screen` 回退。
- [顶部工具栏在窄屏发生拥挤] → 导航按钮使用紧凑水平间距，筛选控件使用两列网格加全宽搜索框，避免逐项纵向堆叠。
- [Sticky 表头与筛选下拉层级冲突] → 表头使用低于筛选控件的 z-index，筛选下拉继续覆盖表格区域。
- [取消 Listbox 模态行为后用户可点击页面其他区域] → Headless UI 外部点击仍负责关闭面板，键盘选择与 Escape 行为保持不变。
- [服务端同步与页面刷新时点不完全一致] → 两者均使用一小时周期且页面按当前筛选重新拉取；最迟在下一轮页面刷新看到新数据。
