# Proposal: 招聘数据聚合页面（/jobs）

## 背景

项目已具备 `python-parser/scrape_smartsheet.py` 脚本，可逆向抓取腾讯文档智能表格中的校招/实习信息（816 条记录）。但当前数据仅落地为本地 JSON/CSV，用户无法在应用内浏览、筛选和投递。

## 目标

在 ResumeCraft 中新增独立页面 `/jobs`，将智能表格招聘数据自动同步到数据库，支持按行业、招聘类型筛选、关键词搜索和按开启时间排序，帮助用户一站式浏览校招/实习信息。

## 成功标准

1. 后台每 6 小时自动执行 Playwright 抓取并更新 `job_postings` 表
2. 用户访问 `/jobs` 可看到完整招聘列表，首屏加载 < 1s
3. 支持按行业、招聘类型筛选，关键词实时搜索，响应 < 200ms
4. 按开启时间倒序排列，最新招聘信息优先展示
5. 数据去重：同一企业+招聘类型视为同一职位，更新而非重复插入

## 边界与非目标

- **不做**：职位与简历的关联匹配、一键投递、简历解析后自动推荐职位
- **不做**：多数据源聚合（当前仅腾讯文档单源）
- **不做**：用户收藏/标记职位功能（后续迭代）
- **速率控制**：单次抓取完整 816 条，Playwright 页面操作间隔 ≥ 2s，避免触发反爬

## 不做的影响

用户需手动下载 JSON/CSV 后在本地浏览，无法实时获取最新招聘动态，信息滞后。

## 范围

| 模块 | 涉及范围 |
|------|----------|
| 数据库 | 新增 `job_postings` 表 + 索引 |
| 后端 | 同步服务（Playwright 调用）、REST API、定时任务调度 |
| 前端 | 独立页面 `/jobs`、筛选组件、搜索、分页、卡片列表 |
| 部署 | 定时任务配置（Cron / 系统服务 / 容器内） |
